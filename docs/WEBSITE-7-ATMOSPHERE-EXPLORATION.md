# 1. Propósito

Este documento define a Atmosfera Oficial do Website do Hub Tributário.

Ele não descreve layouts, componentes ou implementação.

Seu objetivo é estabelecer como o Website deve fazer o visitante se
sentir antes mesmo da leitura do primeiro título.

A atmosfera é uma camada permanente da identidade do produto.

------------------------------------------------------------------------

# 2. O que é Atmosfera

Atmosfera não é decoração. Atmosfera não é efeito visual. Atmosfera não
é tendência.

Atmosfera é a percepção imediata que surge nos primeiros segundos de
contato com o Website.

------------------------------------------------------------------------

# 3. Princípio Central

O Website deve transmitir domínio.

## Sequência emocional oficial

``` text
Competência
        ↓
Confiança
        ↓
Alívio
```

O visitante procura competência. A confiança nasce dessa percepção. O
alívio surge naturalmente depois.

------------------------------------------------------------------------

# 4. Manifesto

O Website deve transmitir:

-   Competência absoluta
-   Precisão
-   Estabilidade
-   Serenidade
-   Presença
-   Cuidado

Jamais deverá transmitir:

-   Ansiedade
-   Urgência
-   Espetáculo
-   Excesso tecnológico
-   Exuberância gráfica

> **Silêncio visual não significa vazio visual.**

O Website deve possuir presença.

------------------------------------------------------------------------

# 5. Atmosfera Oficial

## Silêncio Vivo

Silêncio Vivo representa um ambiente onde tudo parece cuidadosamente
planejado.

Nada chama atenção desnecessariamente.

Mas tudo demonstra qualidade.

O visitante percebe:

-   Profundidade
-   Refinamento
-   Controle
-   Confiança

------------------------------------------------------------------------

# 6. Características Fundamentais

## Papel e Tinta

Transmite permanência.

## Peso e Gravidade

Os elementos parecem repousar naturalmente.

## Luz Indireta

A profundidade surge pela composição.

Nunca por glow.

## Silêncio Habitado

O espaço vazio possui intenção.

## Traço Único

Elementos gráficos devem ser raros e significativos.

------------------------------------------------------------------------

# 7. Densidade Visual

O Website não deverá parecer:

-   Documento
-   Dashboard
-   Landing SaaS genérica

Também não deverá parecer:

-   Site futurista
-   Interface gamer

Deve comunicar um produto premium.

------------------------------------------------------------------------

# 8. Relação com o Raycast

Raycast permanece como referência de:

-   Atmosfera
-   Profundidade
-   Ritmo
-   Acabamento

Nunca de cópia visual.

------------------------------------------------------------------------

# 9. O que NÃO deve existir

-   Gradientes chamativos
-   Glow
-   Neon
-   Partículas decorativas
-   Dashboards ilustrativos
-   Pessoas
-   Escritórios
-   Gráficos genéricos

Toda decisão visual deve possuir propósito.

------------------------------------------------------------------------

# 10. Princípio da Atmosfera

A atmosfera não compete com o conteúdo.

Ela amplifica o conteúdo.

------------------------------------------------------------------------

# 11. Critério de Excelência

Ao abrir o Website, antes da leitura, o visitante deve pensar:

> "Essa empresa domina profundamente o que faz."

------------------------------------------------------------------------

# 12. Critérios de Aprovação

A atmosfera deve:

-   Transmitir competência
-   Reforçar confiança
-   Manter silêncio visual
-   Possuir profundidade
-   Demonstrar acabamento premium
-   Preservar o Art Direction Master
